# 📖 注音小書蟲

給國小一年級孩子的注音閱讀練習網頁 App，專為 iPad 設計（也可以用手機）。

## 功能

- **題庫**：內建 30 篇原創童詩，每個國字旁邊都標了注音。破音字和輕聲已依教育部標準逐字校對。
- **三種顯示**：只有注音（跟安親班白板一樣）／國字＋注音／只有國字（點一下才出現注音）。可切換直書或橫書，也可以調整字體大小。
- **點字發音**：點任何一個字，就會念出讀音，還能把這個字加進「生字本」。
- **每日任務**：每天自動排 5 篇（篇數可調），新文章優先，另外挑 1 篇複習。
- **確認有讀完**：要先 🎤 錄音朗讀（念太快會被擋下），再答對 1 題讀後小問題，才算讀完一篇。
- **幸運輪盤**：當天任務全部完成就能轉一次，轉過後當天鎖定。獎項、權重（機率）、大獎保底都可以自訂。
- **我的獎品**：抽到的獎品是一張兌換券，要由爸媽兌換。
- **月曆**：完成的日子會蓋上 ⭐ 章，並顯示連續天數 🔥。
- **朗讀錄音留作紀念**：
  - 錄音預設永久保留，並向 Safari 申請持久儲存。
  - 在朗讀紀錄按 🤍 可以收藏念得特別好的錄音。
  - **每月紀念冊**：把一個月的錄音打包成壓縮檔，透過分享選單存到 iCloud 雲碟。壓縮檔裡有 `錄音/日期_篇名.m4a`，以及一個可以邊看文章（含注音）邊聽錄音的 `紀念冊.html`。上個月的錄音還沒備份時，⚙️ 會出現紅點提醒。
  - **成長對照**：超過 60 天沒讀的文章會排進複習。讀完後可以對照聽「第一次念」和「今天念」的錄音。
- **爸媽專區**（要先答對一題乘法才能進入）：
  - 設定
  - 獎項與機率
  - 聽朗讀錄音（可依月份查看、只看收藏）、把念不好的文章「退回重讀」
  - 紀念冊：查看儲存空間、匯出每月或收藏精選的紀念冊
  - **新增自訂文章**：例如把安親班白板上的內容打進來，系統會自動產生注音，點一下字就能修正讀音。
  - 資料備份與還原

## 在 iPad 上使用

1. 用 Safari 打開網址（必須是 **https**，錄音才能使用）。
2. 點「分享」→「加入主畫面」，之後就會像一般 App 一樣全螢幕開啟，也可以離線使用。
3. 第一次錄音時，請允許使用麥克風。

所有資料都存在這台 iPad 的瀏覽器裡，沒有帳號，也不會上傳。**從主畫面刪除 App 或清除 Safari 資料，所有資料和錄音都會消失**，所以：
- 錄音：每個月到「爸媽專區 → 紀念冊」存一份到 iCloud 雲碟。
- 進度、獎項、自訂文章：到「爸媽專區 → 資料」匯出備份。

## 部署（GitHub Pages）

這是純靜態網站，不需要建置步驟：

1. 到 repo 的 Settings → Pages。
2. Source 選 `Deploy from a branch`，分支選 `main`，資料夾選 `/ (root)`。
3. 幾分鐘後就能用 `https://<帳號>.github.io/zhuyin-reader/` 開啟。

> 私人（private）repo 的 Pages 需要 GitHub Pro。也可以把 repo 設成公開，或改用 Netlify、Cloudflare Pages 部署。

本機測試：`python3 -m http.server 8000`，再打開 http://localhost:8000 。

## 修改題庫

內建文章放在 `tools/stories_src.py`，改完後重新產生資料：

```bash
pip install pypinyin
python3 tools/build_data.py --review   # --review 會印出逐字注音，方便校對
```

- 只有某一篇要校正的破音字，寫在該篇的 `fix`。
- 各篇共用的詞語讀音（例如「媽媽」的第二個字讀輕聲、「乾淨」的乾讀ㄍㄢ），放在 `build_data.py` 的 `WORD_FIX`。

改版後，記得把 `sw.js` 裡的 `VERSION` 加 1，iPad 才會更新快取。

## 檔案結構

```
index.html            入口
css/app.css           樣式
js/app.js             畫面與流程
js/store.js           資料儲存（localStorage + IndexedDB 錄音）
js/zip.js             紀念冊打包用的 ZIP 產生器
js/zhuyin.js          注音排版
js/stories.js         內建題庫（自動產生）
js/zhuyin-dict.js     常用字注音字典，給自訂文章用（自動產生）
tools/                題庫原稿與產生腳本
sw.js                 離線快取
```
